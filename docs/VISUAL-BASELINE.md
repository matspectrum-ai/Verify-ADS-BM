# Visual Baseline

## Captured target viewports
- Desktop: 1440 x 1000, deviceScaleFactor 1.
- Mobile: 390 x 844, deviceScaleFactor 1.
- Locale: pt-BR.

## Global target styling observed
- Base background: `#070711` for marketing/auth surfaces.
- Dot grid: radial 1px white dots, 40px x 40px spacing.
- Ambient fields: animated blue, purple, indigo and cyan radial gradients with blur.
- Body: Inter.
- Display/brand headings: Poppins.
- Primary CTA gradient: `#3b82f6 -> #6366f1`.
- Marketing nav height: 64px plus bottom border.
- Public legal routes intentionally switch to a light slate surface.

## Comparison rule
A route is not marked visually verified until a screenshot of this repository is captured at the same viewport and compared against the target baseline. Text/DOM equivalence alone is insufficient.
